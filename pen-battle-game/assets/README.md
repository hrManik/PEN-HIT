# Assets Directory

This folder is reserved for optional custom assets (textures, audio clips, icons).

By default, **Pen Battle: Bench Challenge** is 100% self-contained and procedural:
- **Audio**: Synthesized in real-time using the Web Audio API (zero external files, zero latency, works 100% offline).
- **Graphics**: Procedurally rendered using HTML5 Canvas with realistic wood grain desk textures, pen caps, ballpoint tips, clips, reflection highlights, and shadow drops.
- **Icons**: Clean inline SVG icons.

If you wish to substitute custom sound effects (.mp3/.wav) or custom wood grain textures, place them here and update `js/audio.js` and `js/game.js`.
